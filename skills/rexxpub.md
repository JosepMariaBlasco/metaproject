# RexxPub — Skill Subrouter & Overview

## What RexxPub is

RexxPub is a Rexx-based publishing framework. It takes documents
written in Markdown and turns them into web pages, paginated
articles, slides, letters, or books — in HTML or PDF.

The authoring format is Pandoc Markdown (with extensions: footnotes,
tables, bibliographic citations, fenced divs).

## Common core

All pipelines share a two-stage core:

1. **FencedCode.cls** — a Rexx preprocessor that finds fenced blocks
   tagged `rexx` and replaces them with HTML containing semantic
   highlighting generated by the Rexx Highlighter. Everything else
   passes through untouched.

2. **Pandoc** — converts the resulting Markdown (with the Rexx
   blocks already highlighted) into complete HTML5.

What varies between pipelines is what happens before and after
this core.

## Pipelines

| Pipeline | Tool | What it does |
|:---------|:-----|:-------------|
| **Serve** | CGI (Apache httpd) | Serves HTML dynamically. The site rexx.epbcn.com uses this pipeline. |
| **Print** | CGI + Paged.js | Extends Serve: adds `?print=pdf` to paginate in the browser as a DIN A4 article or as slides. |
| **Build** | `md2html` | Generates static HTML from a single file or a directory tree. |
| **Render** | `md2pdf` | Generates PDF from the command line, using pagedjs-cli (headless Chromium) + optionally pikepdf for the outline. |
| **Ebook** | `md2epub` | Generates EPUB directly with Pandoc, without pagedjs-cli or a browser. |

## Document classes

| Docclass | Description |
|:---------|:------------|
| `article` | LaTeX-style paginated article: A4, Times New Roman, justified text, section numbering, footnotes. |
| `book` | Book with chapters. The most complex docclass. |
| `letter` | Formal letter: sender, recipient, opening, closing, and signature blocks. Ragged right, no indent. |
| `slides` | 16:9 presentation. Sans-serif 20pt, one slide per `<h1>{.newpage}`. |

## YAML front matter

RexxPub options are specified under the `rexxpub:` key in the
Markdown document's YAML front matter. Pandoc options
(`bibliography`, `csl`, `highlight-style`) go at the top level.

Main options: `docclass`, `style`, `size`, `section-numbers`,
`number-figures`, `language`, `outline`. Nested groups: `listings:`
and `figures:` for caption control.

Precedence: structural options follow *author-wins* (YAML > URL/CLI
> default). The highlighting `style` follows *reader-wins* (URL/CLI
> YAML > default).

## Dependencies

- **Pandoc** — Markdown → HTML5 transformation.
- **Paged.js / pagedjs-cli** — CSS pagination (Print and Render).
- **Node.js + npm** — needed for pagedjs-cli.
- **pikepdf** (Python, optional) — enables the outline in PDFs.
